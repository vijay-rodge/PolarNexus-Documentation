# Educational Curriculum & Youth Hub

## 1. Pedagogical Adaptation

Located at `pages/08_outreach.py`, this hub features:
- **School Student Guide**: Uses simple analogies (*Earth's giant refrigerator*) to explain ice-ocean interactions.
- **Interactive Polar Quiz**: Gamified 3-question challenges testing student comprehension.
- **Polar Glossary**: Accessible definitions for *polynyas*, *crevasses*, *nunataks*, and *katabatic winds*.
