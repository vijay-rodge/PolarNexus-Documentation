# Human-in-the-Loop Review Dashboard

## 1. Institutional Governance Safeguards

Before any generated content is published externally:
- Outreach officers review drafts in the Admin Console (`pages/09_admin.py`).
- Scientific claims are checked against cited DSpace handles.
- Reviewer approvals are logged in the audit database.
