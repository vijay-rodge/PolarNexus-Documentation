# Statistical Analysis & Extreme Value Theory

## 1. Core Mathematical Formulations

Computes primary statistical parameters deterministically:

```text
Sample Mean:     mu = (1 / N) * sum(x_i)
Sample Variance: sigma^2 = (1 / (N - 1)) * sum((x_i - mu)^2)
Standard Error:  SE = sigma / sqrt(N)
```

Identifies extreme 99th percentile wind gusts and record-breaking cold events.
