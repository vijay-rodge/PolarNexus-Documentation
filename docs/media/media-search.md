# Media Search & Filtering

## 1. Multi-Modal Visual Discovery

Allows users to discover media assets through:
- Free-text semantic queries (*"Show photographs of Bharati station"*).
- Expedition and station filtering.
- Visual type filtering (Satellite Schematics, Sea-Ice Facsimiles, Expedition Life).
