# Development Prerequisites

## 1. System Requirements

- **Operating System**: Windows 10/11, Ubuntu 22.04 LTS, or macOS 14+
- **Python**: Version 3.11, 3.12, or 3.13 (Python 3.13.1 verified)
- **Node.js**: Version 18+ (for Docusaurus documentation portal)
- **RAM**: Minimum 8 GB (16 GB recommended for local vector store and ML training)
- **Disk Space**: 10 GB free storage for PDF bitstreams and datasets
