# Project Directory Structure

## 1. High-Level Folder Layout

- `agents/`: LangGraph routing and state graph.
- `crawler/`: DSpace harvester and PDF downloader.
- `scientific_engine/`: Sandboxed Pandas deterministic analyzer.
- `rag/`: Vectorstore embeddings and chunkers.
- `ml/`: Domain classifier and clustering.
- `database/`: SQLAlchemy database models.
- `streamlit_app/`: Modular UI pages and components.
- `tests/`: Automated pytest test suite.
