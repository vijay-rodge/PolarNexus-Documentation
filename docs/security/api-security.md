# API Security & Defense Mechanisms

## 1. OWASP Top 10 Protections

- **SQL Injection**: SQLAlchemy ORM parameterized queries eliminate SQL injection vulnerabilities.
- **CORS Policies**: Restricts cross-origin requests to approved MoES and NCPOR domain roots.
- **Request Size Limits**: Caps incoming POST payloads at 10 MB.
