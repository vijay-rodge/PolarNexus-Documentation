# User Authentication Protocols

## 1. Institutional RBAC

Implements Role-Based Access Control (RBAC):
- **Anonymous Public**: Read-only query access to public datasets, publications, and outreach materials.
- **Institutional Researcher**: Access to raw NetCDF download streams and advanced analytics.
- **Outreach Officer / Admin**: Permissions to approve AI-generated drafts, retrain ML models, and trigger DSpace crawls.
