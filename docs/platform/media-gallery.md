# Media Gallery & Figure Dissemination

## 1. Visual Dissemination Hub

Located at `pages/07_media.py`, this gallery displays high-resolution photographs, expedition charts, and satellite orbit schematics extracted directly from PDF bitstreams and NCPOR archives:
- Filter by station (*Maitri, Bharati, Himadri*) or media type (*Photographs, Synoptic Charts, Diagrams*).
- Displays exact page numbers and parent report handles for every figure.
