# Polar AI Assistant (LangGraph RAG)

## 1. Interactive Scientific Assistant

Located at `pages/01_assistant.py`, the AI Assistant is the primary conversational interface for researchers, students, and operational planners:
- **Benchmark Presets**: One-click quick queries covering Maitri temperature analytics, 15th Arctic Expedition findings, and school student guides.
- **Interactive Citations Drawer**: Every answer features an expandable drawer displaying exact document titles, author names, DSpace handles, and local file hashes.
- **Timeseries Visualization**: If an inquiry computes numerical data, the assistant automatically renders an interactive Plotly temperature or wind distribution graph alongside the text.
