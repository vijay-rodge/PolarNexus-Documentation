# Intelligent Search & Discovery

## 1. Unified Hybrid Discovery

PolarNexus unifies keyword search, vector similarity retrieval, and deterministic data lookups into a single search bar:
- Users can search by scientific keywords (*"oceanology"*), station names (*"Maitri"*), temporal horizons (*"2012"*), or physical phenomena (*"katabatic winds"*).
- LangGraph routes queries dynamically, guaranteeing that numerical inquiries are evaluated against sensor databases while literature inquiries retrieve peer-reviewed PDF chunks.
