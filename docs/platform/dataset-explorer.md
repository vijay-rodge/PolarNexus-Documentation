# Dataset Explorer (NPDC Catalog)

## 1. Tabular Scientific Data Catalog

Located at `pages/04_datasets.py`, this module catalogs Automatic Weather Station records, CTD ocean soundings, and aerosol datasets:
- Schema detection identifies timestamp formats, physical parameter units, and sample frequencies.
- Outlier detection summaries alert researchers to sensor riming periods or power disruptions.
