# Homepage Dashboard & Metrics

## 1. Executive Portal Dashboard

The homepage dashboard (`app.py`) provides an instant operational overview of India's polar research program:
- **Active Metric Cards**: Real-time counts of Active Stations, Expeditions, Ingested Datasets, Harvested Publications, and High-Resolution Media records.
- **Polar Station Status Cards**: Live operational coordinates and mean meteorological conditions for Maitri, Bharati, Himadri, and IndARC.
- **Intelligent Query Routing Showcase**: Explains the difference between numerical deterministic analysis and semantic literature retrieval.
